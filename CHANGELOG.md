# Changelog

## 0.2.0 — 2026-09-02

First public preview of **Skills Config Manager (CCM)** (Windows).

- Permanent library (canonical, not in effect) vs container (what the agent reads)
- Network library as read-only quarantine; promote before deploy
- Default workspace deploy = copy; non-default = symlink
- Content-hash conflict picker
- Three shelves: Local / Network / Filter (persona funnel)
- UI in Simplified Chinese (default) and English
- Unsigned `.msi` / NSIS installer via GitHub Releases
