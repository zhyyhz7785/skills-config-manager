# E004 · 三壳冷启动与同 fixture 性能实测

> **迁入说明**：原文写于 `CursorConfigManagerWails2`；2026-07-31 合并入本仓 Evaluations，三壳系列编号顺延为 E003–E007（本仓原有双壳 E001/E002 保留）。  
> **测评编号**：E004（接 E003 架构对比）  
> **日期**：2026-07-31  
> **机器**：本机 Windows（与构建产物同机）  
> **目的**：在已有发行/构建产物上补齐 **冷启动秒表** 与 **域路径性能**，含 Wails2。

## 1. 总结论

**结论（已验证·本轮）**：同 fixture 域路径上，三壳扫描预览同量级（约 15–18 ms 中位）；快照以 **Tauri2 最快**，Wails2 / Electron 次之。发行态窗口首现（`MainWindowHandle`）以 **Tauri2 明显最快**，Electron 次之，Wails2 最慢。包体仍是 Tauri ≪ Wails ≪ Electron。

| 问题 | 答案 | 级别 |
|---|---|---|
| 台账快照谁更快？ | **Tauri2** 0.67 ms → Wails2 1.00 ms → Electron 1.31 ms（中位） | **已验证** |
| 固定根扫描预览谁更快？ | **Wails2** 15.1 ms → Tauri2 17.3 ms → Electron 18.1 ms（中位） | **已验证** |
| 发行窗首现谁更快？ | **Tauri2** 0.099 s → Electron 0.504 s → Wails2 0.768 s（中位） | **已验证** |
| 建议？ | 已由 [E007](E007-主力线切换Tauri2-2026-07-31.md) 裁定 **Tauri2 主力**；本表数字支持该选择（包体/窗首现） | **已验证**（决策） |

**度量边界（硬）**：

- **域性能**：无 WebView、无 IPC 往返；对齐 Tauri E002 / Electron headless 脚本语义。  
- **冷启**：`T_hwnd` = 进程启动 → 首次出现非零 `MainWindowHandle`；**不是**列表文字就绪（Research 015 的 T2），也不是 Markdown 可编辑（T3）。

## 4. 冷启动（发行态窗首现）

### 4.1 产物

| 产品 | 路径 | 体积 |
|---|---|---|
| Electron | `E:\Code\CursorConfigManager\release\win-unpacked\CursorConfigManager.exe` | **221.59 MB**（单文件；整目录更大） |
| Tauri2 | `E:\Code\CursorConfigManagerTauri2\src-tauri\target\release\ccm-tauri2.exe` | **6.44 MB** |
| Wails2 | `E:\Code\CursorConfigManagerWails2\build\bin\CursorConfigManagerWails2.exe` | **15.80 MB** |

未测 `*-portable.exe`（含自解压，见 Research 015）。

### 4.2 方法

脚本：`scripts/cold-start.ps1`

- **T0**：`Start-Process`  
- **T_hwnd**：`Process.MainWindowHandle != 0`  
- 每产品 3 轮；轮间强杀进程；取中位  
- **不**测列表就绪 / 杀软首次扫描差异已尽量通过连跑降低，但仍可能存在

### 4.3 结果表（2026-07-31）

| 产品 | T_hwnd 中位 s | 原始轮次 s | ok |
|---|---|---|---|
| **Tauri2** | **0.099** | 0.190 / 0.099 / 0.081 | 3/3 |
| **Electron** | **0.504** | 0.735 / 0.504 / 0.458 | 3/3 |
| **Wails2** | **0.768** | 1.001 / 0.767 / 0.768 | 3/3 |

相对 Electron 中位：Tauri ≈ **5.1× 更快**；Wails ≈ **1.5× 更慢**（窗首现维度）。

### 4.4 解读

- Tauri 窗首现优势与小包体、WebView2 宿主一致，**已验证**于本指标。  
- Wails 同用 WebView2 但 T_hwnd 慢于 Electron：**推断**与首次嵌入前端资源、绑定注入或无边框窗创建路径有关，**待验证**根因（需 ETW/日志，不在本轮）。  
- 用户体感「能点工具栏」可能晚于 T_hwnd；若需 T2，建议下一轮用 UI Automation 探列表控件。
