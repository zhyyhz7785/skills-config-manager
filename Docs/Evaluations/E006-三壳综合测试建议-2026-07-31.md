## 1. 一句话结论

**结论（已裁定）**：以后开发与交付主力为 **Tauri2**；**Electron** 降为维护/对照；**Wails2** 保留壳对照与 Go 实验。bench 数字仍支持「Tauri 适合主力」（包体、窗首现）；大库域吞吐 Wails 曾更快，不改变本决策。

---

## 2. 关键数字一览（已验证）

| 维度 | Electron | Tauri2（主力） | Wails2 |
|---|---|---|---|
| 包体 | portable ~95 MB / unpacked 主程序 ~222 MB | **~6.4 MB** | ~15.8 MB |
| 轻量快照 / 扫描（E004） | 1.3 ms / 18 ms | **0.67 ms** / 17 ms | 1.0 ms / **15 ms** |
| 高压快照 / 扫描 L2（E005） | 43 ms / 286 ms | 71 ms / 282 ms | **30 ms / 187 ms** |
| 窗首现 T_hwnd（E004） | 0.50 s | **0.10 s** | 0.77 s |
| 默认数据隔离 | 主线 APPDATA（现维护线） | **独立 CCM-Tauri2** | 与 Electron 同路径 |
| 原生拖出 | 有 | 有 | **无**（剪贴板） |
| 仓角色（2026-07-31） | 维护/对照 | **开发主力** | 壳实验 |
