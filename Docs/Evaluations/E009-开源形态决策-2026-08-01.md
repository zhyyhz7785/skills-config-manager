## 1. 选项

| 选项 | 含义 | 利 | 弊 |
|---|---|---|---|
| **暂 private（默认）** | 继续自用/协作私有 | 控节奏；检疫叙事不被社区 Issue 冲散 | 无星/无外部贡献 |
| MIT 公开核心 | 根目录加 `LICENSE`（MIT）+ 公开源码 | 对齐 E001「社会主投」、对照 SM | 支持成本；路径/凭证文档须先脱敏 |

## 2. 改为公开的前置条件（建议）

1. 包号与发行说明一致（当前 `0.2.0`）；冷启/帮助五分钟路径手测绿。  
2. README 写清：永久库 ≠ 生效、网络库不可直部署。  
3. 拟定 `LICENSE` 草稿路径：仓库根 `LICENSE`（MIT 正文）；**不**引入 AGPL 依赖作主栈。  
4. 扫一遍设置默认路径与样例，避免泄露本机绝对路径进文档截图。

## 3. 明确不做

- 不因本文件自动 `gh repo edit --visibility public`  
- 不做 AGPL 混栈「自托管市场」叙事
