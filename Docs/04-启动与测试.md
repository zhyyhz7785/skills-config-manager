```bash
node scripts/with-cargo.mjs cargo run --manifest-path src-tauri/Cargo.toml --example probe_sources --release -- --skip-large
```

## 性能计时（无窗）

```bash
npm run bench:perf
```

可选环境变量：`CCM_BENCH_LIBRARY`、`CCM_BENCH_SCAN`、`CCM_BENCH_DEPTH`（默认 5）、`CCM_BENCH_ROUNDS`（默认 3，报中位）。

### 人群漏斗合成基准（无窗 · 2026-08-19）

**结论（合成基准已验证；GUI 待验证）**：无窗脚本测铺池与点档过滤，不代替人手点货架。**漏斗池**（`funnelPool`：当前筛选用的条目数组）切走网络/筛选不清空；点档先过滤表，**功能桶扫描**（`partitionRefine`：按路径/域把剩余列表切成互斥芯片）放到空闲后再填。同机热跑中位见下节命令输出。

```bash
npx tsx scripts/bench-persona.mjs
npx tsx --test src/lib/funnelAnnotateCache.test.ts
```

`CCM_BENCH_N` 默认 4000。同机热跑中位：网络铺池缓存命中 **18.1 ms**；只按人群过滤表 **0.76 ms**。功能桶扫描算法未改（仍约 4 s）。

DEV（`npm run tauri:dev`）控制台看 `[ccm-perf] open shelf:network|filter`、`partitionRefine deferred=1`、`hideMirrors:status`。

## 常见问题

| 现象 | 解决 |
|------|------|
| 扫描很慢 | 收窄 `ProjectScanRoots` |
| 扫描弹出选目录 | 现行不弹：先在设置勾盘符/工作区，再点工具栏「扫描建库」 |
| 列表拖拽无反应 | 网络表行数过大时禁用指针排序；先按源筛选再拖 |
| Port 1430 in use | 结束占用进程；或设环境变量 `CCM_VITE_PORT` 换端口（需同步改 `tauri.conf.json` 的 `devUrl`） |
| 网络库拉取失败 / 443 超时 | 检查 Git 主机可达；进程环境变量或 Windows 系统代理；改用可达 URL；失败半成品 cache 会被清理 |
| 网络库与永久库同路径 | 设置里重选网络根（代码拒绝同路径）；默认应为 `{永久库}\net` |
| 想干净重测 | 设置「测试回厂重置」（可勾选是否删除网络缓存）或删 `catalog.json`（手删会级联清网络缓存/钉选；不删 skills/rules 正文） |
| 设置文件在哪 | AppData 仅 `library-pointer.json`；主体在 `{永久库}\ccm-settings.json` |
