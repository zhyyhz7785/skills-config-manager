## 常见问题

| 现象 | 解决 |
|------|------|
| 扫描很慢 | 收窄 `ProjectScanRoots` |
| 拖出无文件 | 需本地路径；跳过 SMB |
| Port 1420 in use | 结束占用进程 |
| 网络库拉取失败 / 443 超时 | 检查能否访问该 Git 主机（代理/防火墙）；改用可达 URL；失败半成品 cache 目录会被清理 |
| 网络库与永久库同路径 | 设置里重选网络根（代码拒绝同路径） |
