## 数据流

* 筛选漏斗：`includeLocal` / `includeNetwork` / `hideMirrors`（设置「网络库」下；**localStorage** 是浏览器本地键值存储，本处键 `ccm.hideMirrors` 用来记住该开关）→ `funnelPool`（漏斗池：当前筛选用的条目数组；切走网络/筛选货架不清空，条目引用相同则保留原数组）→ 人群/短语/细分芯片 → `NetworkWorkbench`；芯片样式 `.funnel-nav` 两列等宽
* 点人群档：`funnelFiltered` 同步出表；`partitionRefine`（功能桶扫描：按路径/域把剩余列表切成互斥芯片）经 `scheduleIdle`（空闲回调：主线程空下来再跑）填芯片；未选人群且无已选细分则不扫
* 标注缓存：`funnelAnnotateCache` 命中后展开当前 item，只复用人群字段；`isInContainerList` / `isInActiveUse` 跟当前快照；同标志返回同一对象（禁止整对象冻住容器态）
* 渲染热路径：`networkCount` / `localUpperItems` / `libraryAnnotated` / `networkBrowseItems` / `funnelOriginById` 用 `useMemo`；`ClusterSection` 的 `flatFallback={libraryAnnotated}`
* 三货架上部表：本地容器条目、网络浏览、筛选池都走 `NetworkWorkbench`（与下部永久库同一套 `list-item` + `ListEntryBody`——共用列表行主体：容器/种类/文件名，后接分格 **人群**（用 AI 重做哪类本职的粗切）/ **子档**（档内公开领域切片）/ **功能**（该条 skill 的主动作短语）/ 来源，右侧级别；文件名优先压缩；无勾选、无「按层级用途」下拉；**本地上部与永久库**按 L0/L1/L2/未分类分组，**网络与筛选扁平**）
* 永久库行：容器状态（绿在容器 / 灰不在）→ 种类 → 文件名 → 人群·子档·功能·来源 → 级别下拉（仅此区可改）；同组绿在上；路径只在悬停；不再分子组「规范 / 通用」
* 网络行级别只显示「未分类」；右键「转入本地」与「全部放入未分类」（清空意向，转入后进永久库未分类组）

* 网络库：远端 Git → `{NetworkLibraryRoot}/cache/` + `network-index.json` → 用户「存入永久库」→ `catalog.json` upsert（`origins.tool=network`）→ 现有部署

* **侧栏钉选 / 排序 / 容器眼睛**：Rust `snap_nav_only`（`omitNetworkLibraryList`）→ 前端 `mergeNavOnlySnapshot` 保留 prev 的 `networkLibraryItems` / 永久库列表 / `commands`，只换 `networkPopularNav` 或 `projects`/`navNodes`

* 全局工作区：`InWorkArea && enabled && VisibleWorkspaceIds` → 侧栏「工作区」主叶 + `visibleContainerSections`；齿轮展开「备份区域」；`SelectedGlobalTool`=焦点 → `resolve_active_container_root` → deploy/withdraw/refresh

* 项目容器：`pinned` → 侧栏「容器」主叶；`!pinned` → 「隐藏容器」池（齿轮展开）；批量开闭循环 `updateWorkspaceConfig` / `togglePinProject`

* 扫描建库：设置中配置工作区容器根（可跳过部分 / 加额外目录）与 `ProjectScanRoots`（空=盘符）；工具栏扫描不再弹选目录，预览确认后写入 `catalog.projects` + 条目入库

* 布置模式由 `id == DefaultWorkspaceId` 推导（不存每槽 DeployMode）：默认 **copy**；其余工作区域槽 **symlink** 永久库路径

* 多目标部署：**已入仓**——`deploy(..., workspaceIds?)` 多目标；项目 `visibleTools` / `tool_container_roots` → 项目侧多段容器（人手 GUI **待验证**，见 03 H2–H3）

* 设置落盘：AppData `library-pointer.json` → 库内 `ccm-settings.json`；网络默认 `{库}\net`

* 界面语言：浏览器 localStorage 键 `ccm.locale`（locale＝语言区域码）→ `useI18n` 重渲染 GUI 词典；**不**写入 `ccm-settings.json`；Rust/CLI 错误串仍中文

## 硬边界（代码强制）

* 网络根 ≠ 永久库根

* `deploy` / `withdraw` / `save_detail_markdown` 拒绝 `net:` 前缀 id

* 检查更新只标状态；`apply_network_cache_update` 只改网络缓存

* 健康网络缓存：先 `git ls-remote`（只问远端当前提交号、不下载文件）比对本地 HEAD（当前检出的提交），相同则跳过 `fetch`/`clone`（源级，不逐文件比对）

* **默认工作区**禁止 symlink「库＝生效」；非默认 symlink 失败禁止静默降级为 copy

* UI「备份区域」≠ 设置项备份根 `BackupRoot`
