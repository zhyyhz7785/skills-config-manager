# 项目架构

> 面向 AI 阅读。运行主路径：**Tauri 2 + Rust**（纯产品仓，无 Electron / Node sidecar）。

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 壳 | Tauri 2 | WebView2 |
| UI | React `App.tsx` | 全量界面（含网络库分区、多工作区容器段） |
| Bridge | `src/tauri/ccmBridge.ts` | method → Rust |
| 拖出 | `tauri-plugin-drag` + `resolve_drag_file_paths` | OS 文件拖出 |
| 契约 | `shared/ipc.ts` | SSOT（是什么：单一事实来源；起什么作用：前后端 IPC 契约对齐） |
| 性能 | `run_perf_bench` / `examples/bench_perf` | 无窗快照+扫描计时 |

## 模块映射（网络库 Plan/03）

| 职责 | 路径 |
|------|------|

## 模块映射（全局工作区 Plan/04）

| 职责 | 路径 |
|------|------|
| 工作区模型 / 迁移 / 容器根解析 | `src-tauri/src/workspace.rs` |

## 数据流

- 日常 IPC（快照 / Deploy·Withdraw / 扫描建库 / 项目·用途 / 刷新 / 迁入 / 双份 / 打开 / 拖出）→ **Rust**
- 网络库：远端 Git → `{NetworkLibraryRoot}/cache/` + `network-index.json` → 用户「存入永久库」→ `catalog.json` upsert（`origins.tool=network`）→ 现有部署
- 全局工作区：`VisibleWorkspaceIds` → 侧栏叶 + `visibleContainerSections`；`SelectedGlobalTool`=焦点 → `resolve_active_container_root` → deploy/withdraw/refresh
- Config 五件套 → **legacy 空操作**（与主仓无 UI 一致）

## 硬边界（代码强制）

- 网络根 ≠ 永久库根  
- `deploy` / `withdraw` / `save_detail_markdown` 拒绝 `net:` 前缀 id  
- 检查更新只标状态；`apply_network_cache_update` 只改网络缓存  
- 部署目标 = 焦点工作区容器（多目标批量属 Should）
