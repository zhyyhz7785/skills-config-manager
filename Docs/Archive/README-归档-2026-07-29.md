## 使用方法

- 先确认工作面：改 **skills/rules 正文** 还是改 **本仓库代码**——两面隔离，见 [00](00-工作面隔离原则.md)
- 说「**更新日志**」或「**更新文档**」→ AI 同步更新 03/04（及有变化的 01/02/05/06；用户入口大变时可补 07）
- 说「**整理实现细节**」→ AI 追加写入 06（不新建平行文件）
- 说「**写帮助 / 更新帮助 / 用户手册**」→ AI 更新 07（推荐流程 + 等价操作）
- 说「**核心逻辑 / 产品说明**」→ AI 更新 08（痛点、用户、库↔容器、默认边界；不写操作逐步教程）
- 说「**初始化文档**」→ 按固定结构重建骨架
- 做调研 → 写入 `Research/`
- 学概念 → 写入 `Learning/`
- 阶段设计 → 写入 `Plan/`
