# WPF-UI 快速上手

目标：用最少步骤得到一个「看起来像现代 Windows 应用」的窗口。

## 1. 建项目

```powershell
dotnet new wpf -n MyPrettyApp -f net8.0
cd MyPrettyApp
dotnet add package WPF-UI --version 3.0.5
```

`csproj` 需含：

```xml
<TargetFramework>net8.0-windows</TargetFramework>
<UseWPF>true</UseWPF>
```

## 2. 挂主题（App.xaml）

```xml
<Application x:Class="MyPrettyApp.App"
             xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:ui="http://schemas.lepo.co/wpfui/2022/xaml"
             StartupUri="MainWindow.xaml">
  <Application.Resources>
    <ResourceDictionary>
      <ResourceDictionary.MergedDictionaries>
        <ui:ThemesDictionary Theme="Light" />
        <ui:ControlsDictionary />
      </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
  </Application.Resources>
</Application>
```

深色改为 `Theme="Dark"`。本项目默认 Light。

## 3. 换漂亮窗口（MainWindow.xaml）

```xml
<ui:FluentWindow x:Class="MyPrettyApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:ui="http://schemas.lepo.co/wpfui/2022/xaml"
        Title="我的应用"
        Height="640" Width="960"
        WindowStartupLocation="CenterScreen"
        ExtendsContentIntoTitleBar="True"
        WindowBackdropType="Mica">

  <Grid>
    <Grid.RowDefinitions>
      <RowDefinition Height="Auto"/>
      <RowDefinition Height="*"/>
    </Grid.RowDefinitions>

    <ui:TitleBar Grid.Row="0" Title="我的应用"/>

    <StackPanel Grid.Row="1" Margin="24" VerticalAlignment="Center">
      <TextBlock Text="Hello" FontSize="28" FontWeight="SemiBold"
                 Foreground="{DynamicResource TextFillColorPrimaryBrush}"/>
      <TextBlock Text="WPF-UI 已生效" Margin="0,8,0,16"
                 Foreground="{DynamicResource TextFillColorSecondaryBrush}"/>
      <ui:Button Content="主要操作" Appearance="Primary" HorizontalAlignment="Left"/>
    </StackPanel>
  </Grid>
</ui:FluentWindow>
```

代码隐藏类改为继承 `FluentWindow`：

```csharp
public partial class MainWindow : FluentWindow
{
    public MainWindow() => InitializeComponent();
}
```

命名空间：`Wpf.Ui.Controls`。

## 4. 常用控件速查

| 需求 | 优先用 |
|------|--------|
| 按钮 | `ui:Button` + `Appearance`（Primary / Secondary / Danger…） |
| 标题栏 | `ui:TitleBar` |
| 输入 | `ui:TextBox` / `ui:PasswordBox` |
| 侧栏导航 | `ui:NavigationView` |
| 信息条 | `ui:InfoBar` |
| 图标 | `ui:SymbolIcon` 或 Fluent 符号 |

颜色尽量用主题资源，例如：

- `TextFillColorPrimaryBrush`
- `TextFillColorSecondaryBrush`
- `ControlFillColorDefaultBrush`
- `AccentTextFillColorPrimaryBrush`

避免写死 `#333`，换主题时才会一致。

## 5. 好看但不折腾的布局习惯

1. **一层主结构**：侧栏 + 内容，或顶栏 + 内容；不要第一屏堆满卡片。  
2. **间距**：内容区 `Margin="16~24"`，控件间距 `6~12`。  
3. **层级用字色**：主标题 Primary、说明 Secondary，少用描边框「卡片墙」。  
4. **主操作一个 Primary**：其余 Secondary，危险操作用 Danger。  
5. **Mica 即可**：一般不必再加多层阴影、发光。

## 6. 运行与发布

```powershell
dotnet run
dotnet publish -c Release
```

框架依赖 / 单文件自包含见仓库根目录 [发布说明.md](../发布说明.md)。
