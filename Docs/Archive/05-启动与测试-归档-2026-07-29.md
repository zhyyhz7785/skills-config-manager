## 启动步骤

1. `cd e:\Code\CursorConfigManager`
2. `npm install`（首次）
3. `npm run ensure-electron`（Node 20 或出现「Downloading Electron」假启动时）
4. 设计改 UI：`npm run dev:web` → 固定端口 `http://localhost:5180/`（假数据，不启 Electron；可与 `npm run dev` 并行）
5. 功能联调：`npm run dev` → Vite `5173` + Electron 开发窗（勿用浏览器打开 5173，会报 preload 未注入）

生产试跑：`npm run build` → `npm start`。

产物绝对路径（本机仓库）：

| 产物 | 路径 |
|------|------|
| 渲染 | `e:\Code\CursorConfigManager\dist\` |
| 主进程 | `e:\Code\CursorConfigManager\dist-electron\main.js` |
| preload | `e:\Code\CursorConfigManager\electron\preload.cjs` |

## 发行路径（Windows 便携包）

无 NSIS 安装器、无代码签名。形态：`dir`（解包目录）+ `portable`（单文件 exe）。

**冷启动（已验证机制，2026-07-28）**：

| 形态 | 首启成本 |
|------|----------|
| `win-unpacked\CursorConfigManager.exe` | **推荐日常用**；无自解压；代码侧已懒加载 Crepe、启动快照跳过无用 `configItems` 扫描 |
| `*-portable.exe` | **另含首次自解压**（约 95MB 级），感觉更慢；与业务代码无关 |
| `npm start` | 无解压；同 win-unpacked 量级 |

Crepe（Markdown 编辑器）在**首次打开编辑页签**时再加载（独立 chunk ≈1.4MB）；首屏主包已从约 1.7MB 降至约 0.3MB 量级。

如何区分 `npm run dev` / `build`+`start` / `win-unpacked` 测什么、怎么冷启秒表：见 [Research/015](Research/015-冷启动测试三种形态差异-2026-07-28.md)。

### 用时总览

| 步骤 | 命令 / 动作 | 参考用时 | 何时必跑 |
|------|-------------|----------|----------|
| 安装依赖（含 electron-builder） | `npm install` | 首次视网络；国内可用 npmmirror | 缺依赖时 |

## 测试方法

### 自动化门禁（开发机）

```text
npm run typecheck
npm run verify:all
```

可选：`npm run verify:guards`（台账健康 / U4 删失败 / 路径穿越）；`node scripts/bench-hash-memo.mjs 50`（哈希 memo 冷/热耗时）。

说明：`verify-nested-cursor-scan.mjs`、`verify-explorer-softener.mjs` 依赖本机路径或人工步骤，**未**纳入 `verify:all`。

**最近自动化结果（已验证，2026-07-28）**：`npm run typecheck` 通过；`npm run verify:all` **11/11** 通过（含 guards、move/冲突、md-minimal-merge、分类、扫库范围等）。

### 冒烟（约 5 分钟）

1. 启动后永久库非空（默认或已配置路径）
2. 启动扫描对话框可取消；确认后条目进库且容器文件移走
3. 右键项目：移入置顶容器或容器 / 上移下移 / 编辑 / 删除

   * **删除**：先检查项目根 `.cursor`。无文件（或不存在）则直接删空 `.cursor`/空 `.claude`/空 `.agents` 并从台账移除，避免下次「扫描项目」回流。有文件则确认是否先迁入备份库；确定=迁库后尽量删空标记目录再去登记；取消=仅去登记、保留磁盘。
4. 右键库条目：放入 / 移出 / 标签等
5. 拖分割线 → 重启后栏宽仍在
6. 「设置永久库」可改路径；刷新后列表更新

### 复制语义 / 冲突 / 刷新 / 双开（手测）

对齐 04 P0 与「部署改为复制语义」Plan；**勿在无人值守下对真实永久库做破坏性操作**。下列待本机勾选。

**放入 / 移出**

* [ ] 放入：永久库正本仍在；容器出现副本；列表「容器中」与「永久库」同 `entryId` 可见，永久库行有绿边（双份）
* [ ] 移出（同哈希）：静默删容器副本；库正本不变；台账离开双份态
* [ ] 移出（异哈希）：弹出冲突窗；元数据（路径/哈希/大小/mtime/预览）可读

**冲突窗四选项（异哈希移出或刷新决议）**

* [ ] 保留库版：删容器副本，库正文不变
* [ ] 用容器覆盖库：库正文=容器；容器按产品语义处理正确
* [ ] 另存新 id：库内新条目（可带哈希后缀），原正本保留
* [ ] 跳过：磁盘与台账均无改

**刷新对账**

* [ ] 仅「容器存活副本 ↔ 库正本」哈希不同才弹窗；同哈希不弹
* [ ] 有冲突时：确认前不对账写删（预览只读）；确认后才应用决议并对账
* [ ] 无冲突：刷新本身完成对账，无误删
* [ ] 决议后再次刷新：已决议项不再误弹（决议键未被吞掉）

**双开页签 + 对比**

* [ ] 同条目分别点「容器中」「永久库」→ 两编辑签并存（标题「· 容器 / · 库」）
* [ ] 右键或页签行「对比」→ 只读并排 Diff（左容器、右库）；不可编辑
* [ ] 各编辑签 `Ctrl+S` 分别写对应侧路径

**护栏抽样（真实库慎用；优先对照 verify:guards / 临时库）**

* [ ] 截断或损坏 `catalog.json` 后操作：不得用空账覆盖磁盘；应有可读错误或可从 `.bak` 恢复
* [ ] 库外 / 越界路径相关操作被拒绝（toast 或错误，磁盘库外文件未被动）
