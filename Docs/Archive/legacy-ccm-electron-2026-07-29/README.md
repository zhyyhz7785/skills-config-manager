## 使用方法

- 说「**更新日志**」或「**更新文档**」→ AI 更新 03（及有变化的 01/02/04/05）；**不**改 06
- 说「**记经验 / 踩坑记录 / 整理实现细节**」→ AI 追加写入 05（先过判定门槛，不新建平行文件）
- 说「**生成帮助 / 更新帮助 / 用户手册**」→ 按 L0-project-help-doc 写/改 06
- 说「**初始化文档**」→ 按固定结构重建骨架（不含 06；06 首次「生成帮助」时再建）
- 做调研 → 写入 `Research/`
- 学概念 → 写入 `Learning/`
- 阶段设计 → 写入 `Plan/`
- 评估结案 → 写入 `Evaluations/`
