# L0 / L1 / L2 / 未分类 划分逻辑（2026-07-26 简化）

> 依据（已验证）：`purposeTaxonomyHelper.ts`（`deriveLevel` / `suggestLevel` / `deriveClusterRoot`）、`libraryCatalogService.buildClusterTree`、永久库树拖拽定级。  
> 对照原原则见 [008](008-自动归类与原划分原则对比-审视优化-2026-07-26.md)。

---

## 1. 结论（现行 1A / 2A）

| 信号 | 自动层级 |
|------|----------|
| 项目容器（`project:` scope / origins） | **L2** |
| 用户级 Cursor 目录的 **rule**（`global` / `user-global`，非 library-disk） | **L0** |
| 其余（技能等、仅永久库、来源不明） | **未分类**（无 `tags.level`） |
| 用户拖拽 / 右键「设为层级」 | 写入或清除 `tags.level`（**L1 仅人工**） |

废除：`alwaysApply`→L0、默认一律 L1、L0 下「顶级规则」二级组、按文件名推断。

---

## 2. 树结构

```text
永久库
├── L0          ← 叶子直挂（无「顶级规则」套娃）
├── L1          ← 仅 tags.level=L1；可有用途二级
├── L2          ← 可有「项目 / 名」二级
└── 未分类      ← 叶子直挂；待用户拖入上三级
```

拖条目到 L0/L1/L2/未分类 组头即可定级（多选一并改）。

---

## 3. 自动归类

建议与上表一致；未分类项默认不预勾（有用途建议时仍可勾选只写用途）。确认写入 `tags.level` 或清除；不改文件名。
