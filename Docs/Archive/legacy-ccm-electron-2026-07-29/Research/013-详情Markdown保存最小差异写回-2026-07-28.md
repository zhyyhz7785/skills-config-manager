# 详情 Markdown 保存最小差异写回

> 日期：2026-07-28  
> 状态：已落地（最小差异写回 + 化妆品锚点 + 按原文推断 bullet/rule）

## 现象

在 CCM 详情 Crepe 中「只改一点文字再删掉 / 只改一行」后保存，VSCode 与 CCM 冲突比对出现大片 diff：

- 分隔线 `---` ↔ `***` 整篇翻转
- 列表标记 `-` ↔ `*`
- 表格列对齐空格重排、`~` → `\~`
- 纯 CRLF 文件被写成 frontmatter CRLF + 正文 LF 的混合换行

用户直觉：编辑后文本被整体重写。判断正确。

## 根因（已验证）

1. **dirty 基线错位**  
   `savedBodyRef` 存的是磁盘原文，而 `markdownUpdated` 给的是 remark-stringify 重新序列化的全文。两者永不相等 → 输入后撤回仍 dirty → Ctrl+S 写出整篇规范化文本。

2. **序列化风格 ≠ 原文风格**  
   对容器原文 `SKILL.md`（正文约 422 行）做「解析→序列化」往返实测：
   - remark-stringify **默认**：约 **删 96 / 增 99** 行
   - 对齐 `rule:'-'`、`bullet:'-'` 等后：约 **删 36 / 增 39** 行（剩余主要为表格对齐与转义）

3. **EOL 未保留**  
   容器原文纯 CRLF；旧保存路径写出 LF 正文 → VSCode 按行全红。

4. **主进程无条件写盘**  
   `saveDetailMarkdown` 即使内容相同也 `writeFileSync` 并刷新 `contentHash`，加重冲突窗噪音。

5. **第一轮落地后残留（2026-07-28 续）**  
   `bullet` 仍写死为 `'-'`，原文 `*` 列表与基线 `-` 字面不对齐 → O↔S0 锚点断裂 → `serialize(parse(merged)) === S1` 回验失败 → **整篇 S1 兜底**，标题小改仍把全文 `*` 洗成 `-`（L1T00 规则实测）。

## 机制

```text
O  = 磁盘原文正文（保留原 EOL / 原风格）
S0 = create 后 crepe.getMarkdown()（序列化基线；stringify 按 O 推断）
S1 = 当前序列化正文

dirty  := S1 !== S0
写盘   := merge(O, S0, S1)   （O↔S0 锚点用 normalizeLineForAnchor）
回验   := 软提示；merge 非 null 即写 merged（不再因回验失败整篇洗符号）
仅 null := 整篇 S1 + dominant EOL 兜底
```

`mergeSerializedEdit`（`src/lib/markdownMinimalMerge.ts`）：

1. `S0 === S1` → 直接返回 O（零字节变化）
2. `buildLineDiff(O, S0, normalizeLineForAnchor)` 取 same 行作锚点（`*`/`-`、`***`/`---`、表格空格视为同）
3. `buildLineDiff(S0, S1)` 归并改动块 `{ s0Start, s0End, addLines }`
4. 块间照抄 O 原行（含各自 EOL）；块内写入 `addLines` + dominant EOL
5. 锚点交叉 / 区间非法 → `null`（才走整篇兜底）

`inferRemarkStringifyOptions(O)`：按原文行首列表 / 分隔线多数票设 `bullet` / `rule`，create 时写入 `remarkStringifyOptionsCtx`。

## 落地文件

| 路径 | 作用 |

## 已知取舍

- **编辑落在表格内部**：该表格块可能按序列化风格重排（远端表格不动）。mdast-util-gfm-table 固定补齐对齐，不做逆向还原。
- **已被旧逻辑写坏的永久库副本**：不自动回滚；可用冲突比对以容器正本覆盖。
- **回验软失败**：仍写 `merged.body`（保原文标记）；仅合并返回 `null` 才整篇序列化 + dominant EOL。

## 验证

- `node scripts/verify-md-minimal-merge.mjs`：零改动字节相同；CRLF 单行编辑保留 `***`/表格；`*` 列表+标题小改仍保留 `*`；`inferRemarkStringifyOptions`；锚点交叉 → null
- `npm run typecheck`
- `npm run verify:all`（已纳入上项）
- 手动：输入后撤回 → 脏点消失且 Ctrl+S 不写盘；只改标题保存 → 列表标记与原文一致
