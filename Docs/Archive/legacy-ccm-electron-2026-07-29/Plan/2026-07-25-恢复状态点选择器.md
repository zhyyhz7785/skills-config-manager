# 恢复状态点选择器（08 §4.3）

**状态**：已实施（2026-07-25）

## 结论

- 台账字段 `LibraryEntry.checkpoints`：`{ at, reason, path, contentHash, note? }`，最多 20 条。
- 写入：扫描登记、部署、移出/迁入永久库、恢复成功。
- 恢复 UI：勾选条目 + 目标下拉（首次发现 / 状态点）；支持仅恢复选中项。
- **边界**：只回路径，不存/不还原正文快照。

## 关键代码

| 位置 | 作用 |
|------|------|
| `shared/types.ts` | `EntryCheckpoint`、`appendEntryCheckpoint` |
| `libraryCatalogService.ts` | `normalizeCheckpoint` 读盘兼容 |
| `skillIngestService.ts` | 写入 + `previewRestoreAll` / `restoreAllToInitialWithResolutions` |
| `appController.ts` / `App.tsx` | IPC 与恢复确认窗 |

## 验收

1. 扫描后 catalog 条目有 `checkpoints`（registered）
2. 部署后再恢复可选 deployed 状态点
3. 多选仅恢复选中；无选中预览全量
4. 库正本不因恢复被搬走
5. 旧 catalog 无 checkpoints 不报错
