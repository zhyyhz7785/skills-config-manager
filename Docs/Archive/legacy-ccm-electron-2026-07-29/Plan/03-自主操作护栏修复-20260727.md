## 1. 「自主操作」指什么

软件在**用户未确认**时写盘 / 改台账 / 删容器文件，尤其是：

| 行为 | 风险 |
|---|---|
| `catalog.json` 解析失败后静默变空并写回 | 整库台账丢失 |
| 每次 UI 快照软登记写台账 | 放大残缺 load 窗口；无感改账 |
| 迁入同哈希删副本失败仍标已迁入 | 台账与磁盘不一致 |
| 无决议默认 `saveAs` | 静默另存出 `id-哈希` |
