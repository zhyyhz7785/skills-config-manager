# 仓库逻辑修订：部署改为复制语义 + 冲突信息增强

**合并自两份计划**：
1. 核心语义修订：部署改为复制（备份库常驻正本）
2. UI增强：冲突比对弹窗显示完整元数据

---

## 问题根源（已验证）

**核心问题**：当前 `deployToContainer()`（`skillIngestService.ts` 924–969行）执行的是**物理移动**（Move语义）：
- 库文件被搬到容器后，`isInLibrary=false`
- 备份库目录里不再有该文档
- 结果："文档在使用中 ⇒ 备份库为空"

**用户期望**：备份库应该始终保留文档的正本（备份的本质）

**现状**：
- `moveIntoBackupLibrary()` 已实现"内容相同自动删容器副本"（663-692行）
- 但前提"库内常驻正本"缺失，导致该逻辑无法触发
- 冲突弹窗信息不够详细（只有路径和前400字符预览）

---

## 目标方案：部署改为复制 + 智能比对

### 新状态模型

台账（catalog.json）中 `isInLibrary` 与 `deployedPath` 不再互斥，新增**双份态**：

| 状态 | isInLibrary | deployedPath | 磁盘 | 说明 |
|---|---|---|---|---|
| 仅在库 | true | 空 | 只有库正本 | 未部署状态 |
| 双份（新常态） | true | 容器路径 | 库正本 + 容器副本 | 部署后常态 |
| 仅容器（遗留） | false | 容器路径 | 只有容器文件 | 旧Move产物 |

**工作流程**：
1. **部署**：从库**复制**到容器（库保留正本）
2. **存回备份库**：
   - 哈希相同 → 自动删除容器副本（静默）
   - 哈希不同 → 弹出冲突窗让用户选择
3. **撤回**：删除容器副本，库正本保留

```typescript
export function copyFileCrossVolume(src: string, dest: string): void {
  fs.mkdirSync(path.dirname(dest), { recursive: true });
  fs.copyFileSync(src, dest);
}

export function copyDirectoryCrossVolume(src: string, dest: string): void {
  fs.mkdirSync(dest, { recursive: true });
  const entries = fs.readdirSync(src, { withFileTypes: true });
  for (const entry of entries) {
    const srcPath = path.join(src, entry.name);
    const destPath = path.join(dest, entry.name);
    if (entry.isDirectory()) {
      copyDirectoryCrossVolume(srcPath, destPath);
    } else {
      fs.copyFileSync(srcPath, destPath);
    }
  }
}
```

```typescript
function buildConflictWithMetadata(params: {
  key: string;
  operation: 'scanBuild' | 'moveIntoBackup' | 'restoreInitial';
  suggestedId: string;
  kind: LibraryItemKind;
  sourcePath: string;
  targetPath: string;
  existingEntryId: string;
  sourceHash: string;
  targetHash: string;
}): PathConflictItem {
  const sourceStat = fs.existsSync(params.sourcePath) 
    ? fs.lstatSync(params.sourcePath) 
    : null;
  const targetStat = fs.existsSync(params.targetPath) 
    ? fs.lstatSync(params.targetPath) 
    : null;

  const sourcePreview = readPreview(params.sourcePath);
  const targetPreview = readPreview(params.targetPath);

  return {
    ...params,
    sourcePreview: sourcePreview.content,
    targetPreview: targetPreview.content,
    sourceSize: sourceStat?.size,
    targetSize: targetStat?.size,
    sourceModified: sourceStat?.mtime.toISOString(),
    targetModified: targetStat?.mtime.toISOString(),
    sourcePreviewLines: sourcePreview.lines,
    targetPreviewLines: targetPreview.lines,
  };
}

function readPreview(filePath: string): { content: string; lines: number } {
  if (!fs.existsSync(filePath)) {
    return { content: '（文件不存在）', lines: 0 };
  }
  const stat = fs.lstatSync(filePath);
  if (stat.isDirectory()) {
    const entries = fs.readdirSync(filePath).slice(0, 10);
    return {
      content: `[文件夹，包含 ${entries.length} 项]\n` + entries.join('\n'),
      lines: entries.length,
    };
  }
  try {
    const content = fs.readFileSync(filePath, 'utf-8');
    const lines = content.split('\n').slice(0, 15);
    return {
      content: lines.join('\n'),
      lines: lines.length,
    };
  } catch {
    return { content: '（无法读取）', lines: 0 };
  }
}
```
