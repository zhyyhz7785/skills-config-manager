## 1. 这是什么 / 适合谁

**CCM**（Cursor Config Manager，本机配置台账管理器）把散落的 skills / rules 收进**永久库**记账，再**部署**到 Cursor / Claude 等工具**容器**才生效。开源技能先进入**网络库**（只读检疫橱窗）再晋升。

适合：多项目同名规则分叉、要定稿对账的人。不适合只想「市场一键装 15+ Agent」。

## 2. 五分钟上手（最优默认路径）

1. 打开 CCM → 确认永久库（设置 /「设置永久库」）。设置主体在库内 `ccm-settings.json`，不是只在 AppData。  
2. 设置 → 扫描：勾选要扫的工作区/盘符并保存 → 工具栏「扫描建库」→ 只预览相对台账的变更 → 确认入库。同名不同内容不进扫描列表，用「刷新」。  
3. 选中条目 → 「部署 → {焦点工作区}」。**默认工作区**用复制（copy）；**非默认**用符号链接（symlink，跟随库改动）。  
4. （可选）设置勾选第二工作区 → 侧栏「工作区」切换焦点 → 再部署；或右键「部署全部」。  
5. 改容器副本后点「刷新」→ 哈希冲突窗人选。

## 3. 推荐日常工作流

扫描建库（增量）→ 部署焦点或全部 → 定期刷新对账；开源则网络货架拉取 → 转入本地 → 再部署。

## 4. 功能操作详解

### 扫描建库

- **目标**：相对台账发现未登记变更并安全入库。  
- **推荐流程**：设置勾选扫描范围并保存 → 工具栏「扫描建库」→ 无变更则结束；有变更则勾选确认。同名不同哈希提示后用「刷新」。  
- **等价操作**：工具栏「扫描建库」（不弹选目录）。

### 部署

- **目标**：永久库条目进入焦点工具容器。  
- **推荐流程**：侧栏选「工作区」焦点 → 勾选条目 →「部署」；多工作区可用「部署全部」。  
- **注意**：网络库项不能直部署；须先转入永久库。默认槽 copy、非默认 symlink（**待验证**手感）。

### 冲突决议

- **目标**：同名不同哈希时人选，不静默覆盖。扫描**不再**开此窗。  
- **推荐流程**：「刷新」→ 看 diff →「全部采用…」或逐项确认。

### 网络库检疫

- **目标**：只读浏览开源 → 晋升永久库。  
- **推荐流程**：侧栏网络货架 → 官网★ / 社区眼睛显隐 → 粘贴 Git URL 或标题栏刷新拉取（可见进度，**待验证**）→ 条目右键「转入本地」→ 再部署。  
- **可选**：社区标题栏调候选 N、排序；设置「网络库」下可开 **隐藏镜像**（同源下去掉语言后缀后同名只留一条）。右键可开条目/源缓存目录（**待验证**）。

### 筛选货架

- **目标**：按人群 / 子档 / 短语收窄已索引条目。  
- **推荐流程**：点左侧「筛选」→ 点人群档（如软件后端）→ 必要时再点子档/短语 → 转入永久库后再部署。  
- **注意**：网络行不能直部署。隐藏镜像开关在设置，不在筛选左侧。

### 设置迁库与测试回厂

- **目标**：设置与台账同库，便于整库备份与干净重测。  
- **推荐流程**：日常改设置保存即可；反复测干净安装 → 设置「测试回厂重置」（可勾选是否清网络缓存，不删 skills/rules 正文）。入口文案 **待验证**。

## 5. 常见问题

| 现象 | 解决 |
|---|---|
| 部署按钮灰 / 失败 | 确认焦点与永久库；网络项先晋升 |
| 扫描弹出选目录 / 冲突窗 | 扫描不弹选目录、不应再弹冲突；同名不同内容请「刷新」 |
| Toast「无变更」 | 正常：相对台账无新项 |
| 拉取失败 / 超时 | 检查网络或系统代理；换可达 URL |
| 想干净重测 | 测试回厂或删 `catalog.json`（会清网络侧） |
| `~\.cursor\rules` 不生效 | 跨项目须粘贴进 Cursor Settings → Rules |
