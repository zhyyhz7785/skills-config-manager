## 1. 这是什么 / 适合谁

**CCM**（Cursor Config Manager）是本机配置台账管理器：把散落的 skills / rules 等资产收进**永久库**记账，再按需**部署**到 Cursor / Claude 等工具**容器**才生效。开源技能先进入**网络库**检疫，晋升后才能编辑与部署。

适合：多项目同名规则分叉、要定稿对账的人；不适合只想「市场一键装 15+ Agent」的场景。

## 2. 五分钟上手（最优默认路径）

1. 打开 CCM → 确认已配置永久库（工具栏「设置永久库」或设置页）。  
2. 点「扫描建库」→ 选项目/条目确认入库；若同名内容不同，在冲突窗逐项或「全部采用…」决议。  
3. 在列表选中已入库条目 → 看工具栏「部署 → {焦点工作区}」→ 部署。  
4. （可选）设置里勾选显示 Claude 等第二工作区 → 点侧栏切换焦点 → 再部署，文件写入对应容器根。  
5. （演示冲突）改容器里副本内容 → 点「刷新」→ 出现哈希冲突窗 → 选保留库或保留容器。

## 3. 推荐日常工作流

扫描 / 迁入 → 冲突决议 → 部署到焦点容器 → 定期刷新对账；开源则网络库浏览 → 存入永久库 → 再部署。

## 4. 功能操作详解

### 扫描建库

- **目标效果**：发现本机项目/容器中的配置并登记进永久库。  
- **推荐流程**：
  1. 工具栏「扫描建库」  
  2. 预览确认 → 有冲突则决议  
- **等价操作**：

| 入口 | 步骤 |
|---|---|
| 工具栏 | 「扫描建库」 |
| 空白处菜单 | 视版本含扫描入口时 |

### 部署到焦点工作区

- **目标效果**：永久库条目复制到当前焦点工具容器。  
- **推荐流程**：
  1. 侧栏选全局工作区焦点（或项目）  
  2. 勾选条目 → 「部署」  
- **注意**：网络库条目不能直部署；须先「存入永久库」。

### 冲突决议

- **目标效果**：同名不同哈希时人选策略，不静默覆盖定稿。  
- **推荐流程**：
  1. 看左右 diff  
  2. 底部「全部采用…」或逐项选后「确认应用」  

### 网络库检疫

- **目标效果**：只读浏览开源 → 晋升进永久库。  
- **推荐流程**：侧栏「网络」→ 拉取源 → 工作台选层级 → 「转入本地」→ 再部署。  

### 漂移报告 / 部署配方

- **目标效果**：设置页生成「与库不一致」清单；或保存条目列表为一键部署配方。  
- **推荐流程**：设置 →「生成漂移报告」/「用当前选中保存」配方 →「一键部署」。  

## 5. 常见问题（用户向）

| 现象 | 解决 |
|---|---|
| 部署按钮灰 / 失败 | 确认焦点工作区与永久库已配置；网络库项先晋升 |
| 刷新无冲突但内容看着不同 | 比对的是内容哈希；空白/换行可能已规范化 |
| 想关掉顶部提示条 | 点「知道了」，或设置里关「显示首次提示」 |
