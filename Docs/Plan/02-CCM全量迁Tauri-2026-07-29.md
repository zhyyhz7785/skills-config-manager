## 4. Kill

- 同 fixture 与 Electron 行为对不齐且修不动 → 退回主仓 Electron  
- M1 后 **>8 周**无厚域退役 → 停迁或退回  
- 含 Node 却宣称纯 Tauri 体积胜出 → 禁止  
- 长期双发行无日落 → 禁止
