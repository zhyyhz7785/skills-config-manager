# 04 · 全局工作区与多容器

> **现行计划（本能力）**：将侧栏「通用 → 互斥单选工具」升级为**全局工作区**：可勾选显示 1～N 个工作区；每工作区 1:1 绑定容器根；列表并列多段「容器中」分区；默认工作区 Cursor。  
> 产品机制见 [01-核心逻辑](../01-核心逻辑.md)；对照 Skills Manager「全局工作区」语义，**不**照搬其「主区同时只开一个详情」。

## 总论

**结论（建议）**：工作区 = Agent/工具槽位；容器根与工作区绑定；可见多选 + 焦点驱动部署；永久库 / 网络库 / 冲突人选不变。UI 定调**工装仪表盘**（延续 VS Code 系壳）。

---

## 1. 术语

| 术语 | 是什么 | 起什么作用 |
|------|--------|------------|
| **工作区（Workspace）** | 一个 Agent/工具槽位（如 Cursor） | 导航、默认设置、容器绑定的单位 |
| **全局工作区** | 用户级（非项目）工作区集合 | 侧栏升级后的分区名 |
| **容器** | 该工作区工具实际读取的目录 | 部署/撤回/「容器中」对账目标 |
| **可见工作区** | 用户勾选要在 UI 展示的工作区集合 | 控制侧栏叶与列表容器分区数量 |
| **默认工作区** | 未多选操作时的主上下文（初始 Cursor） | 部署目标默认、新建设置默认落点 |
| **焦点工作区** | 侧栏当前高亮的工作区 | 多可见时 deploy/withdraw/refresh 写入目标 |

---

## 2. 目标与边界

**结论（建议）**：Must 做全局多容器并列；项目多工具与批量多目标部署放 Should。

| 做 | 不做（本期） |
|----|--------------|
| 内置 cursor / claude / codex 工作区 | SM 式中央库 + 15+ Agent 矩阵 |
| 可见多选 + 默认 Cursor | 削弱永久库对账 |
| 每工作区容器根可改 | Docker 容器语义 |
| 列表多段「容器中 · {名}」 | 主列表做成 All Agents 卡片总览 |
| 焦点驱动 deploy | 项目侧多工具容器（Should） |

## 3. MoSCoW

| 优先级 | 范围 |
|--------|------|
| **Must** | 工作区实体；可见多选；默认=Cursor；容器根可改；多段容器/曾用于分区；焦点驱动 deploy/withdraw/refresh；设置页工作区表；工装仪表盘视觉；文档同步 |
| **Should** | 「全部可见」快捷；部署目标多选；项目工作区多工具 |
| **Could** | 关联任意目录为容器；SM 式卡片总览 |
| **Won't** | 削弱护城河；Docker 语义；SM 一键矩阵 |

## 4. 数据与 IPC

**结论（建议）**：在 `AppSettings`（PascalCase）增补工作区字段；旧 `SelectedGlobalTool` 迁移为焦点/默认。

| 字段 | 说明 |
|------|------|
| `DefaultWorkspaceId` | 默认 `"cursor"` |
| `VisibleWorkspaceIds` | 可见 id 列表 |
| `Workspaces` | `{ Id, Enabled, DisplayName, ContainerRoot }` |
| `SelectedGlobalTool` | 兼容保留 = **焦点工作区** id |

迁移：无新字段时 `visible=[SelectedGlobalTool]`、`default=SelectedGlobalTool`、三内置填默认根。

IPC：`setWorkspaceVisibility` / `setDefaultWorkspace` / `updateWorkspaceConfig`；`setNav` 的 tool 继续写焦点；快照含 `workspaces`、`visibleContainerSections`（多段列表 DTO）。

## 5. UI / 审美（frontend-design）

**结论（建议）**：定调**工装仪表盘（industrial / utilitarian）**——在现有 `styles.css` VS Code Light 变量上精炼，不另起营销站皮肤。

| 维度 | 做法 | 禁止 |
|------|------|------|
| 空间 | 每可见工作区一段；顶栏「容器中 · {名}」；一节一事 | 圆角卡片网格、KPI 条、浮动 badge |
| 焦点 | 侧栏 + 分区顶栏共用 accent / 左侧 2px 色条；工具栏「部署 → {焦点}」 | glow、全圆 pill、紫渐变 |
| 辨识 | `--ws-cursor` / `--ws-claude` / `--ws-codex` 仅色条与侧栏小点 | 每区整套主题 |
| 字体 | 延续 Segoe / YaHei | Inter / Space Grotesk「改版」 |
| 动效 | 焦点切换过渡、分区展开 opacity；仅 2～3 处 | 营销式 stagger |

设置页：紧凑工作区表（启用 / 显示名 / 容器根 / 默认），与现控件高度一致。
