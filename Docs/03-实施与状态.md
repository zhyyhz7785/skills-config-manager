## 最近变更

### 2026-08-19（文档整理）

- **结论**：`Docs/` 瘦身——本文件只留阶段/快照/近两周摘要 + 手测表；旧逐日日志与 Research 逐条表进 Archive。

- **待验证**：导航是否好找（你扫一眼）。

### 2026-08-19（界面与漏斗）

- **结论**：网络侧栏用户可见串走 `t()`（按键取当前语言字符串）；切走网络不清 **漏斗池**（`funnelPool`：当前筛选用的条目数组）；点 **技能包** 芯片按 **assignment**（条目 id → 芯片 id 的分桶表）立刻出表，**功能桶扫描**（`partitionRefine`）空闲再跑。永久库在容器中文件名变绿；漏斗标注缓存只复用人群字段。
- **已验证**：i18n 单测 5/5；点芯片过滤 5608 ms → 1.88 ms；铺池命中 63.4 → 18.1 ms；`typecheck`。
- **待验证**：H33 / H50 / H53 / H54。

### 2026-08-16～18（现行界面定稿）

- **三货架**：本地 / 网络 / 筛选；筛选左侧漏斗；下部固定永久库窗；隐藏镜像在设置。
- **列表**：上下同一套行（种类 · 文件名 · 人群/子档/功能/来源/级别）；网络与筛选扁平；永久库 id 随层级 `S0`/`R0`；无「容器」列。
- **漏斗**：十档（软件前端 / 软件后端）；功能桶优先于来源整包；默认全量出表；全维搜索。
- **i18n**：默认 `zh-CN`，设置切 `en`。
- **已验证**：各日单测/`typecheck`。人手 GUI 见下表 H16–H52。

### 2026-07-30～08-15（折叠）

网络拉取部分克隆、设置精简、扫描改到设置、开眼刷新与并行路数、社区 50 源、界面去掉 skills.sh/配方/OS 拖出。
